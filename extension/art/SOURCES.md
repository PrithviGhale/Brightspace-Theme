## Local 1.7.0 character worlds (not published)

Additional art was retrieved from these publisher/official character pages on 2026-10-22. Exact image URLs are recorded in [world-sources.json](world-sources.json). Images are bundled locally; no runtime requests to these sites.

- Spider-Man (revised): [Marvel Spider-Verse announcement](https://www.marvel.com/articles/comics/sdcc-2019-miles-morales-goes-back-to-the-multiverse-in-spider-verse-1), Wendell Dalit cover art from Marvel CDN. Additional Spider-Verse cover by Giuseppe Camuncoli via [Midtown Comics](https://www.midtowncomics.com/product/1376629). Marvel artwork. The game screenshots have been removed.
- Cyberpunk: Edgerunners (revised): Earthrise scene matching the user reference, retrieved from [PixieWall](https://www.pixiewall.com/wallpaper/cyberpunk-edgerunners-david-lucy-couple-4k-2814). CD PROJEKT RED/TRIGGER anime artwork; no endorsement implied. Separate Lucy/David cutouts and old ensemble art have been removed.

- Sugarbunnies: [official Sanrio profile/gallery](https://www.sanrio.co.jp/characters/sugarbunnies/), twin rabbits and cookie-pattern gallery illustration. The [National Diet Library's 2007 animation DVD record](https://ndlsearch.ndl.go.jp/books/R100000002-I000009129006) confirms the requested anime-era title; the UI uses Sanrio's character/gallery art rather than anime screenshots.
- Attack on Titan: [official anime visual gallery](https://aot-portal.com/special-gallery/kv/), first and second Season 1 key visuals with the wall/Colossal Titan, Eren, Mikasa, Armin and Scouts. Rights remain with the creators/publishers/production committee.
- Genshin Impact (revised 1.7.2): matching Moonlight Amidst Dreams festival key art from [the official PlayStation version 5.4 article](https://blog.playstation.com/2025/01/26/20250127-gi/). Old landscape and party images removed.

Unofficial fan themes. Artwork rights remain with the respective owners. Attribution is not a license grant. No 1.7.0 push or public release has been made.

## Local 1.7.4 cleanup

Spider-Man, Cyberpunk/Edgerunners and the Genshin five-character gallery have been removed. Earlier source notes above are historical; world-sources.json lists only remaining downloadable artwork. The gallery-only Raiden/Kazuha/Hu Tao assets were removed. Remaining Furina/Nahida art is still used as page backgrounds.

Heading fonts are bundled under extension/fonts from the Google Fonts repository: [Marcellus](https://github.com/google/fonts/tree/main/ofl/marcellus), [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), [Bitter](https://github.com/google/fonts/tree/main/ofl/bitter). Each includes its original OFL.txt license. Genshin tries an already-installed HYWenHei face first; the proprietary game font is not bundled. No runtime requests to Google Fonts or artwork sources.


## Local 1.7.5 UI assets and typography

Genshin game UI icons (HoYoverse), mirrored by the Genshin Impact Wiki: [Paimon Menu/UI icon catalogue](https://genshin-impact.fandom.com/wiki/Category:UI_Icons) for Icon_Paimon_Menu, Icon_Mail_Paimon_Menu and Icon_Notices; [Chat](https://genshin-impact.fandom.com/wiki/Chat) for Icon_Dialogue_Talk_White. Original transparent PNG files, unmodified; exact download URLs recorded in world-sources.json. No hardcoded unread dot is baked into the Paimon image; existing native alert indicators remain independent.

Titan font research: the [user-linked forum](https://www.dafont.com/forum/read/218843/attack-on-titan-font) suggests Ditty, Cloister Black and Angel Wish without confirming the original. The first two are tried via local font lookup only. Bundled fallback [Pirata One](https://github.com/google/fonts/tree/main/ofl/pirataone) is an independently designed Gothic face, not the official Titan logo font. Its unmodified TTF and original OFL license are included in fonts/. No runtime font download.
